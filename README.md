# Marushu's Personal Linux Dot Files

A project where I slowly build up by Arch Linux installation. Good place to show others what I have done and also serves as a online backup.

Recently updated to hyprland's lua config. The old configuration can be found within the old config folder.

## What's included here:

- **Window Manager**: Hyprland with custom keybinds and configuration
- **Shell and Widgets**: Quickshell

## Hyprland Plugins used:

**split-monitor-workspaces** - https://github.com/zjeffer/split-monitor-workspaces
