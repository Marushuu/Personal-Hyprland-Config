# Marushu's Personal Linux Dot Files

A project where I slowly build up my Arch Linux installation. Good place to show others what I've done. Also serves as an online backup.

Recently updated to hyprland's lua config. The old configuration can be found within the old config folder.

## What's included here:

Runtime and Rendering

- **Hyprland v0.55+** - Wayland compositor
- **Quickshell** - QML Shell framework
- **Qt6** - Qt6 libraries and QML Engine

System Tools

- **PipeWire** - Audio and Video server
- **NetworkManager** - Network manager
- **BlueZ** - Bluetooth
- **Brightnessctl** - Brightness control
- **Playerctl** - Media player control
- **Cava** - Audio visualizer
- **Swaync** - Sway notification daemon
- **wl-clipboard** - Wayland clipboard
- **Cliphist** - Clipboard history manager
- **Slurp** - Wayland region selection tool
- **Grimblast** - Hyprland screenshot helper

Wallpapers

- **Swaybg** - Static wallpaper tool
- **Mpvpaper** - Dynamic wallpaper tool

Hyprland Extra

- **Hyprlock** - Lock screen manager
- **Hypridle** - Idle management daemon
- **Hyprpolkitagent** - Hyprland's polkit agent
- **Xdg-desktop-portal-hyprland** - XDG Desktop Portal for Hyprland
- [**split-monitor-workspaces**](https://github.com/zjeffer/split-monitor-workspaces) - Hyprland Plugin for Split Monitor Workspaces

Theming

- **Nord** - Main Color Scheme, using Utterly Nord for QT and Nordic for GTK
- **Iosevka Nerd Font Mono** - Main Font
